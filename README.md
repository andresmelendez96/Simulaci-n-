## Descripción

Este proyecto implementa un Modelo Oculto de Markov (HMM) para simular un sistema de detección de fraude financiero.

El sistema genera transacciones bancarias probabilísticas y utiliza inferencia mediante el algoritmo de Viterbi para identificar posibles comportamientos fraudulentos a partir de montos observables.


## Objetivo

Simular un sistema de monitoreo financiero capaz de inferir transacciones legítimas, sospechosas o fraudulentas utilizando probabilidades de transición y emisión en un Modelo Oculto de Markov.
